# 开源贡献

这里放两样东西，因为它们的用途完全不同：

**一是复盘。** diff 本身不传递思考——3 行改动和 300 行改动看起来都只是"改了代码"。真正有价值的是怎么找到问题的、为什么这样改，以及放弃了哪些看起来更正规的方案。所以每篇复盘按「现象 → 定位 → 根因 → 取舍」写。

**二是索引。** 由 GitHub Actions 每周拉取 API 自动生成，**只显示真实存在的提交记录**。这也是我把索引和复盘分开放的原因：复盘可以讲故事，索引不行——它必须经得起核对。
